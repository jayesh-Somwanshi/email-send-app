This application uses the Gmail API to send emails. To make it work, you need to configure a Google Cloud Project and provide the credentials below.

1. Go to the Google Cloud Console.

2. Create a new project and enable the Gmail API.

3. Configure the OAuth Consent Screen as "External".

4. Create OAuth 2.0 Client IDs for a Web Application.
